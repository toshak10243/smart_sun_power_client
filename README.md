# Smart Sun Power CRM

Enterprise CRM & Project Pipeline Management System for Smart Sun Power.

## Project Structure
- **/backend**: Node.js & Express REST API with Redis Caching, Bull Queues, Rate Limiting & Automated Backups.
- **/frontend**: React & Vite Web Dashboard & Back-Office Pipeline Operations Portal.
- **/app**: Flutter Cross-Platform Mobile Application for Sales Reps & Operations with FCM Push Notifications.
